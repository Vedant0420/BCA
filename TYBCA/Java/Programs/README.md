# Java Practice Programs – TYBCA End-Term

Each program is in its own `.java` file. The file number matches the program number. The expected output is written as a comment at the bottom of every file.

> Why `P01_` and not `1.`? Java class names can't start with a number or contain a dot, so `P01_` is the closest name that works.

**How to run:** open a terminal in the unit folder (`cd Unit1` or `cd Unit2`), then:

```
javac FileName.java
java FileName
```

## Unit 1

| # | Topic | File | Run |
|---|-------|------|-----|
| 1 | Hello World + 3 comment types | `P01_HelloWorld.java` | `javac P01_HelloWorld.java && java P01_HelloWorld` |
| 2 | Sum, average, largest & smallest of an array | `P02_ArrayDemo.java` | `javac P02_ArrayDemo.java && java P02_ArrayDemo` |
| 3 | Matrix addition (2D array) | `P03_MatrixAddition.java` | `javac P03_MatrixAddition.java && java P03_MatrixAddition` |
| 4 | Print command-line args + add two numbers | `P04_CommandLineArgs.java` | `javac P04_CommandLineArgs.java && java P04_CommandLineArgs 10 20` |

| 6 | Student input using BufferedReader | `P06_BufferedReaderDemo.java` | `javac P06_BufferedReaderDemo.java && java P06_BufferedReaderDemo` |
